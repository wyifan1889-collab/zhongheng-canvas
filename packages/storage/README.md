# `@infinite-canvas/storage`

这是服务端对象存储的最小接缝，不是已经启用的媒体上传功能。

- 当前只定义 `put/get/delete` 和安全对象键校验。
- 不选择阿里云 OSS、腾讯云 COS 或其他供应商，不读取凭据，不生成公开 URL。
- `createMemoryObjectStorage()` 仅用于测试；生产环境没有“缺少供应商时退回内存”的路径。
- `createFileObjectStorage(rootDirectory)` 是当前服务器硬盘方案的私有适配器：只写专用目录，不启动文件服务器，不生成公开 URL。
- 账号归属、项目归属、媒体类型、上传前检查、额度、删除规则、私有下载授权和跨设备恢复必须由 API 业务层另行确定并验收。

接入真实上传路由前，需要先确定文件类型/大小与总额度、最小权限、目录所有权、备份、失败和未知结果处理，以及用户可见的上传与删除交互。当前适配器尚未接入用户上传路由。
