# 无限画布用户指南

这份指南对应当前本机账户版本。当前页面可以登录、编辑本机画布和管理云端图片/视频/音频素材；云端画布正文同步仍未公开开启。

## 开始使用

1. 打开 `/account`，注册或登录账户。
2. 首次注册需要完成页面的人机验证和邮箱验证。找不到邮件时先检查垃圾邮件，再使用页面的重新发送入口。
3. 登录成功后会自动进入 `/canvas`。直接访问画布地址但没有有效会话时，也会先回到账户入口。
4. 忘记密码时打开“找回密码”，申请邮件后从邮件链接进入重置页，设置新密码，再返回登录。

密码需要 8–128 个字符；密码和邮箱验证码不要发到聊天、日志或截图中。

## 画布和本机草稿

画布编辑、项目列表和未接入云保存的草稿保存在当前浏览器的本机存储中，并按账户隔离。刷新页面或重新打开同一个项目后，已保存的本机草稿可以恢复。

右上角账户入口用于查看当前登录状态和退出。需要时可确认“退出所有设备”，它会让当前账户的全部登录会话失效，同时退出当前页面；本机画布和草稿不会上传、迁移或删除。退出后，之前账户的本机草稿不会出现在另一个账户下。不同画布可以在多个窗口同时编辑；同一画布在两个窗口同时保存发生冲突时，系统保留双方内容并暂停冲突页的自动保存，先导出或处理冲突后再继续。

画布库支持导出选中画布和导入 `.zip` 备份。导入会先检查项目结构、媒体清单、文件大小和压缩包路径；发现缺失媒体或异常路径时会整体拒绝，不会只导入半个项目。导入前建议保留原有本机草稿，确认恢复结果后再清理旧副本。

## 云端素材

在“资产”面板中可以打开云端素材选择器，支持手动上传和选择图片、视频、音频。云端素材属于当前账户，初始额度为 1 GB；上传、私有预览、插入画布和删除都会显示结果与额度变化。

云端素材删除前，如果仍被当前账户的云画布正文引用，服务会拒绝删除并提示先解除引用。画布正文只保存媒体 ID，不保存 OSS 对象键、公开 URL 或 AccessKey。

当前云端素材功能已在本机页面验收。正式云画布正文保存、跨设备正式入口和扩容购买尚未开放，不要把“本机自动保存”理解成云端备份。

## 窄屏页面

窗口较窄时，画布顶部会隐藏次要直达按钮，标题会截断，右侧工具区可以横向滚动。文档入口仍可从画布菜单打开；账户、配置、语言、主题和 Agent 入口会保留。

## 常见问题

- **登录后没有进入画布**：确认页面显示登录成功，再刷新 `/canvas`；如果账户会话无效，会自动回到账户入口。
- **提示服务不可用**：先确认本机 API 和网页服务都在运行，再刷新页面。不要重复提交注册或重置邮件，系统会对邮件和验证接口限流。
- **图片没有显示**：检查当前账户是否仍然登录；云端媒体读取失败时，系统会保留正文并进入只读状态，不会用空内容覆盖画布。
- **看不到云端画布**：这是当前配置的预期行为，`cloudCanvas=false`。云端素材入口和云端画布正文是两个独立开关。
- **AI 配置在哪里**：当前 AI API Key 和 Base URL 仍由浏览器前端配置并保存在本机，不会由账户服务代管。

## 当前未开放能力

生产 Turnstile、多邮箱/手机端完整验收、退出所有设备的真实多设备页面验收、正式云画布正文同步、旧素材自动迁移、扩容套餐和支付入口仍需单独的生产配置与验收，当前不会显示成已可用功能。
